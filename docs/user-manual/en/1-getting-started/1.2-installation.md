# 1.2 Installation Guide

## Official Channels and System Requirements

Only download Codex Switch from **trusted release channels**, **GitHub Releases**, or the project source repository. Any "Codex Switch" site or client that asks for payment, top-ups, or login credentials is not official.

| System | Minimum Version | Architecture |
|--------|-----------------|--------------|
| Windows | Windows 10 or later | x64 / ARM64 |
| macOS | macOS 12 (Monterey) or later | Intel (x64) / Apple Silicon (arm64) |
| Linux | glibc 2.35+ and WebKitGTK 4.1 (see the [Linux](#linux) section below) | x64 / ARM64 |


## Optional: Install the Tools to Manage

Codex Switch itself does not need Node.js or any other runtime. It manages tools you have already installed, such as Claude Code and Codex. If a tool is not installed yet, you can install Codex Switch first and then install the tool using either of the methods below.

### Method 1: One-Click Install in Codex Switch (Recommended)

Click "Apps" at the bottom of the sidebar. The list shows the current and latest version of each tool. Tools that are not installed have an install button next to them, and installed tools can be updated individually; you can also choose here which apps show in the sidebar. Supported tools: Claude Code, Codex, Gemini CLI, Grok Build, OpenCode, OpenClaw, Hermes, Pi, and MiniMax Code. Claude Desktop is a desktop app and cannot be installed here. See [1.3 Interface Overview](./1.3-interface.md#apps-page) for details.

### Method 2: Install Each Tool the Official Way

| Tool | Install Command (macOS / Linux) |
|------|---------------------------------|
| Claude Code | `curl -fsSL https://claude.ai/install.sh \| bash` or `npm i -g @anthropic-ai/claude-code` |
| Codex | `npm i -g @openai/codex` or `brew install --cask codex` |
| Gemini CLI | `npm i -g @google/gemini-cli` |
| Grok Build | `curl -fsSL https://x.ai/cli/install.sh \| bash` or `npm i -g @xai-official/grok` |
| OpenCode | `curl -fsSL https://opencode.ai/install \| bash` or `npm i -g opencode-ai` |
| OpenClaw | `npm i -g openclaw` |
| Hermes | `curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh \| bash` |
| Pi | `npm i -g @earendil-works/pi-coding-agent` |

For Claude Desktop, MiniMax Code (which Method 1 can install), and installation on Windows, refer to each tool's official documentation.

Installing with npm requires Node.js. Each tool requires a different version (for example, Claude Code needs 22 or later, and OpenClaw needs 24.x at 24.16 or later, or 26.1 or later). Installing the current LTS release is recommended; npm will tell you if your version is too old.

> 💡 **Tip**: If npm downloads are slow for you in mainland China, append `--registry=https://registry.npmmirror.com` to the command, or set the mirror globally:
> ```bash
> npm config set registry https://registry.npmmirror.com
> ```
> The mirror occasionally lags behind. If you end up with a version older than the official one, temporarily switch back to the official registry `https://registry.npmjs.org`.

3. Follow the prompts to complete installation

The installation directory page includes a **Create a desktop shortcut** option. Clear it to skip desktop shortcut creation; you can still launch the app from the Start menu. It is selected by default on a fresh install. Upgrades preserve whether the desktop shortcut exists, so a deleted shortcut is not recreated automatically. You can also clear the option during an upgrade to remove an existing desktop shortcut. If the desktop shortcut cannot be created (for example, the Desktop folder is read-only or blocked by security software), the installer skips it and finishes the installation instead of failing or rolling back.

For a silent installation, pass `CREATEDESKTOPSHORTCUT=0` to skip desktop shortcut creation:

```powershell
msiexec /i "CodexSwitch-v{version}-Windows.msi" /qn CREATEDESKTOPSHORTCUT=0
```

Note: If nothing happens when you run the installer, right-click the file, choose `Properties`, and on the `General` tab check `Unblock` under `Security`.

## macOS

### Option 1: Homebrew (Recommended)

```bash
# Install
brew install --cask cc-switch
```

Update to the latest version:

```bash
brew upgrade --cask cc-switch
```

### Option 2: Manual Download

1. Download `CodexSwitch-v{version}-macOS.dmg` (recommended) or `CodexSwitch-v{version}-macOS.zip`. This is a Universal build that runs natively on both Apple Silicon and Intel Macs
2. Open the DMG, or extract the zip to get `Codex Switch.app`
3. Drag it to the Applications folder

### Signed and Notarized

Codex Switch for macOS is signed and notarized by Apple. You can install and open it directly — no extra steps needed.

## Linux

The Linux version of Codex Switch requires **glibc 2.35+** and **WebKitGTK 4.1**, e.g. Ubuntu 22.04+, Debian 12+, and recent Fedora. RHEL / Rocky / Alma 8–9 ship system libraries that are too old and are not supported yet.

### ArchLinux

Install using an AUR helper:

```bash
# Using paru
paru -S cc-switch-bin

# Or using yay
yay -S cc-switch-bin
```

### Debian / Ubuntu

1. Download `CCodexSwitch-v{version}-Linux-x86_64.deb` or `CCodexSwitch-v{version}-Linux-arm64.deb` for your architecture
2. Install:

```bash
sudo dpkg -i CCodexSwitch-v{version}-Linux-*.deb

# If there are dependency issues
sudo apt-get install -f
```

### Fedora and Other RPM-Based Distributions

1. Download `CodexSwitch-v{version}-Linux-x86_64.rpm` or `CodexSwitch-v{version}-Linux-arm64.rpm` for your architecture
2. Install:

```bash
sudo dnf install ./CodexSwitch-v{version}-Linux-*.rpm
```

### AppImage

For distributions that meet the system requirements above but have no matching package.

1. Download `CodexSwitch-v{version}-Linux-x86_64.AppImage` or `CodexSwitch-v{version}-Linux-arm64.AppImage` for your architecture
2. Add execute permission:

```bash
chmod +x CodexSwitch-v{version}-Linux-*.AppImage
```

3. Run:

```bash
./CodexSwitch-v{version}-Linux-*.AppImage
```

### Flatpak

Official releases do not include a Flatpak package. If you need one, you can build it yourself from the `.deb`; see [flatpak/README.md](https://github.com/FerryboatSeranade/ccc-switch/blob/main/flatpak/README.md) in the repository.

## Verify Installation

After installation, launch Codex Switch:

1. The app window displays correctly
2. A Codex Switch icon appears in the system tray
3. The app list in the left sidebar shows the managed apps you chose to display; click one to open its provider page

## Auto Update

Codex Switch includes built-in auto-update functionality:

- Automatically checks for updates on startup
- Displays an update prompt in the UI when a new version is available
- Click to download and install

You can also manually check for updates in "Settings → About".

## Uninstall

### Windows

- Uninstall via "Settings → Apps"
- Or run the uninstaller in the installation directory

### macOS

- If installed via Homebrew: `brew uninstall --cask cc-switch` (add `--zap` to also delete configuration data)
- If installed manually: move `Codex Switch.app` to Trash
- Optional: Delete the configuration directory `~/.cc-switch/`

### Linux

```bash
# Debian/Ubuntu
sudo apt remove cc-switch

# Fedora and other RPM-based distributions
sudo dnf remove cc-switch

# ArchLinux
paru -R cc-switch-bin
```
